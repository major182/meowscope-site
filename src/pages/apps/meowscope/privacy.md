MeowScope（以下「運営者」）は、アプリ「MeowScope」（以下「本アプリ」）で扱う情報について、次のとおり定めます。

## 1. 集める情報

| 種類 | 内容 |
|---|---|
| アカウントの情報 | メールアドレス、パスワード（元に戻せない形に変えて保存します）、名前、アイコンの画像 |
| 猫の情報 | 名前、生年月日、性別、写真、持病 |
| 記録 | 記録の種類と日時、詳細（量・病院の名前・次の予定日など）、メモ、写真、投稿したときの名前 |
| おうちの情報 | おうちの名前、メンバー、招待のリンク（60分で使えなくなります） |
| 設定 | 通知の設定、ウィジェットのボタンなどの設定 |
| 不具合の情報 | 本アプリで起きたエラーの内容、OS の種類と版、本アプリの版、起きた日時、問い合わせ番号。送る前に、メールアドレスに見える文字を伏せます |
| 通信の記録 | サーバーへの通信の日時・種類・結果、利用者を見分ける番号、問い合わせ番号。メールアドレス・パスワード・記録の中身は残しません |
| お問い合わせ | お問い合わせのメールアドレスと内容 |

次の情報は集めません：位置情報、端末の連絡先、広告のための識別子。また、利用状況の解析や広告の仕組みは使っていません。

## 2. 使う目的

- 記録を保存し、同じおうちのメンバーと共有するため
- 通知（投薬の時刻、いつもとの違い、記録忘れ、誕生日など）を出すため。通知は端末の中で作ります
- パスワードの再設定の確認コードを、メールでお送りするため
- 不具合を調べて直すため
- お問い合わせにお答えするため

## 3. 保存する場所と期間

- 情報は、利用者の端末と、運営者が管理するサーバー（日本国内）に保存します。通信は暗号化します（HTTPS）
- 端末では、ログインの情報を OS の安全な保管場所に置きます
- 保存の期間は、アカウントを削除するまでです。削除したデータは、ほかの端末に削除を伝えるため90日のあいだ削除の印を付けて残し、その後に完全に消します
- サーバーのデータは、毎日バックアップを取り、7日分を保管します
- 通信の記録と不具合の情報は、一定の量を超えると古いものから消えます

## 4. 第三者への提供と委託

法令に基づく場合を除き、利用者の同意なく第三者に提供しません。サービスの提供のため、次の事業者に情報の取り扱いを任せています。

| 事業者 | 任せていること | 扱う情報 |
|---|---|---|
| Resend, Inc.（米国） | 本アプリからのメール（パスワードの再設定の確認コード）と、お問い合わせへの返信の送信 | メールアドレス、メールの内容 |
| Cloudflare, Inc.（米国） | お問い合わせのメールの受け取りと転送、ドメインの名前の管理 | お問い合わせのメールアドレスと内容 |
| Tailscale Inc.（米国） | 現在、本アプリをお使いいただいている方の端末とサーバーをつなぐ通信の経路の提供 | 通信の経路の情報（記録の中身は暗号化され、見えません） |

## 5. 生成 AI への送信

現在、本アプリは生成 AI に情報を送りません。この機能を加えるときは、このポリシーを改定し、利用者が操作したときだけ送ります（写真は送りません）。

## 6. 削除・開示・訂正

- アカウントと記録は、本アプリの中で削除できます。方法は[アカウントの削除](/apps/meowscope/account-deletion/)のページをご覧ください
- 保存している情報の開示・訂正・削除のご希望は、下のお問い合わせ先へご連絡ください。ご本人であることを確かめたうえで対応します

## 7. このポリシーの改定

本アプリの扱う情報や使い方が変わるときは、このポリシーを改定し、このページでお知らせします。
