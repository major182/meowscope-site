## 1. はじめに

major182 の事業 MeowScope（ドメイン `meowscope.dev`）の、公開の Web サイトを作る。

- **目的**：
  - 事業とアプリを紹介する
  - アプリのストア（Google Play）の審査に必要なページを置く（プライバシーポリシー・アカウントの削除の案内）
  - 問い合わせの窓口を示す
- **見る人**：
  - アプリの利用者と、利用を考えている人
  - ストアの審査をする人
  - 事業やポートフォリオの連絡をする人
- **アプリ**：1本目は、猫の体調管理アプリ MeowScope（以下「アプリ MeowScope」）。今後アプリが増えても、同じ形でページを足せるようにする

## 2. システム化の概要

静的なサイト（あらかじめ作った HTML を配るだけのサイト）として作り、GitHub Pages で `https://meowscope.dev` に出す。サーバーやデータベースは持たない。

| URL | ページ | 機能 ID |
|---|---|---|
| `/` | トップ（事業の紹介とアプリの一覧） | F-PG-01 |
| `/about/` | 運営者の情報 | F-PG-02 |
| `/contact/` | 事業の連絡 | F-PG-03 |
| `/apps/meowscope/` | アプリ MeowScope の説明 | F-PG-04 |
| `/apps/meowscope/privacy/` | プライバシーポリシー | F-PG-05 |
| `/apps/meowscope/terms/` | 利用規約 | F-PG-06 |
| `/apps/meowscope/account-deletion/` | アカウントの削除の案内 | F-PG-07 |
| `/apps/meowscope/support/` | よくある質問・使い方・問い合わせ | F-PG-08 |
| 見つからないページ | 404 のページ | F-PG-09 |

URL の作りとドメインの設定は、MeowScope のデプロイ設計書 2.4 と同じにする（C-02）。

## 3. 業務ルール（BR-xx）

| ID | 内容 |
|---|---|
| BR-01 | アプリのページは `/apps/<アプリ名>/` の下に置く。アプリ名は英小文字とハイフン（例：`meowscope`）。事業のページ（`/about/` など）とぶつけないため |
| BR-02 | アプリの問い合わせ先は `support@meowscope.dev`、事業の連絡は `contact@meowscope.dev` とし、ページごとに使い分ける |
| BR-03 | プライバシーポリシーと利用規約は、アプリごとに置く。集めるデータや使い方がアプリごとに違うため |
| BR-04 | プライバシーポリシーは、アプリが実際に扱うデータ（アプリの要件定義書）に沿って書く。アプリの扱いが変わったら、同じ時期にポリシーも直し、改定日を書く |
| BR-05 | アプリ MeowScope の一般公開の前は、利用規約を「下書き」と明記する。一般公開の前に見直して仕上げる（アプリ MeowScope の要件 NF-LG-01） |
| BR-06 | URL は、英小文字とハイフンで、最後を `/` にする。一度出した URL は変えない（ストアやアプリに書くため） |

## 4. 機能要件（F-XX-xx）

| ID | 内容 |
|---|---|
| F-PG-01 | トップ：事業の一言の紹介と、アプリの一覧（名前・一言の説明・アプリのページへのリンク） |
| F-PG-02 | 運営者の情報：運営の名前（MeowScope）、運営者、連絡先（`contact@meowscope.dev`）。載せる範囲は Q-01 |
| F-PG-03 | 事業の連絡：`contact@meowscope.dev` と、アプリの問い合わせは各アプリのページへ、という案内 |
| F-PG-04 | アプリ MeowScope の説明：何ができるか、対応する端末（Android・Windows）、入手の方法、各ページ（ポリシー・規約・削除・サポート）へのリンク |
| F-PG-05 | プライバシーポリシー：集める情報、使う目的、保存の場所と期間、第三者への提供（メールの送信に使うサービスなど）、削除の方法、問い合わせ先、制定日と改定日 |
| F-PG-06 | 利用規約：一般公開までは下書きと明記する（BR-05） |
| F-PG-07 | アカウントの削除の案内：アプリの中で削除する手順、アプリを使えない人がメールで削除を頼む方法（`support@meowscope.dev`）、消えるデータと残るデータ（おうちに残す記録の選び方を含む）、消えるまでの期間 |
| F-PG-08 | サポート：よくある質問、問い合わせ先（`support@meowscope.dev`）、問い合わせのときに添えてほしいもの（アプリの版・端末・問い合わせ番号） |
| F-PG-09 | 404 のページ：ページが見つからないことと、トップへのリンク |
| F-NV-01 | すべてのページに共通の上部（運営の名前・トップへのリンク）と下部（運営者の情報・事業の連絡へのリンク、著作権の表示）を置く。アプリのページでは、そのアプリのページどうしのリンクも置く |

## 5. データ要件

データベースは持たない。ページの文章はリポジトリの中のファイルとして持つ。

## 6. 非機能要件（NF-XX-xx）

| ID | 内容 |
|---|---|
| NF-SC-01 | HTTPS だけで配る（GitHub Pages の「Enforce HTTPS」） |
| NF-SC-02 | 見る人の追跡をしない。アクセスの解析・広告・Cookie・外部のスクリプトを使わない（プライバシーポリシーとの食い違いを作らないため） |
| NF-SC-03 | 公開リポジトリに、秘密の値・個人の連絡先・クラウドの識別子を書かない |
| NF-UX-01 | スマートフォンの幅（360px）からパソコンの幅まで、横にはみ出さずに読める |
| NF-UX-02 | 文字の大きさと色の差（コントラスト）を読みやすくし、`lang="ja"`、画像の代わりの文（alt）を付ける |
| NF-UX-03 | 端末の明るい・暗い表示の設定に合わせる |
| NF-MT-01 | リンク切れがないことを CI で確かめる |
| NF-MT-02 | アプリを足すときは、アプリの一覧とアプリのページのファイルを足すだけで済むようにする |
| NF-CS-01 | 費用をかけない（GitHub Pages と Cloudflare の無料の範囲） |

## 7. 制約条件・前提条件（C-xx）

| ID | 内容 |
|---|---|
| C-01 | 公開は GitHub Pages、ドメインは `meowscope.dev`（Cloudflare で取得し、DNS も Cloudflare） |
| C-02 | URL の作りとドメインの設定は、MeowScope のデプロイ設計書 2.4 を正とする。変えるときは、あちらを先に直す |
| C-03 | 日本語だけで作る。英語の版を足すときは、URL の頭に言語を足す（例：`/en/apps/meowscope/privacy/`） |
| C-04 | 招待のリンク（`/apps/meowscope/invite`）と App Links の確かめのファイル（`/.well-known/assetlinks.json`）は、アプリ MeowScope の一般公開のときに足す（アプリ MeowScope の NF-SC-11、Q-30） |

## 8. 受け入れ基準

| ID | 内容 | 要件 |
|---|---|---|
| AC-01 | 2章のすべての URL が開き、F-NV-01 のリンクでたどれる | F-PG-01〜09、F-NV-01 |
| AC-02 | Google Play の審査の項目に、プライバシーポリシーとアカウントの削除の案内の URL を入れられる | F-PG-05、F-PG-07 |
| AC-03 | スマートフォンの幅で、どのページも横にはみ出さない | NF-UX-01 |
| AC-04 | CI で、組み立てとリンク切れの確かめが通る | NF-MT-01 |

## 9. 未決事項（Q-xx）

| ID | 内容 |
|---|---|
| Q-01 | （一部決定）運営者の情報に載せる範囲。2026-11-24 決定：無料の間は、活動名（major182）とメールアドレスを載せ、「氏名と住所は、ご請求があれば遅滞なく開示します」と書き添える（個人情報保護法で、求められたら答えられるようにしておくため）。**収益化（有料のアプリ・アプリ内課金・広告）を始めるときに必ず見直す**：特定商取引法の表示（実名・住所・連絡先。請求により開示する形も可）が要り、Google Play でも開発者の氏名と住所がストアに出る |

## 10. 用語集

| 用語 | 意味 |
|---|---|
| 静的なサイト | あらかじめ作った HTML などのファイルを、そのまま配るサイト。サーバーで処理をしない |
| GitHub Pages | GitHub が無料で提供する、静的なサイトの置き場所 |
| App Links | Android で、決まった https のリンクを、確かめが通ったアプリだけが開ける仕組み |
