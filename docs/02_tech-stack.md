## 1. この文書の目的

サイトを作る技術と、選んだ理由・選ばなかった理由を残す。

## 2. 選定の条件

- 費用をかけない（NF-CS-01）
- アプリが増えても、ファイルを足すだけでページを増やせる（NF-MT-02）
- 規約などの長い文章を、HTML の書き方に気を取られずに書ける
- 外部のスクリプトや追跡を入れずに作れる（NF-SC-02）
- 利用者が学習中のため、仕組みが分かりやすく、標準的なやり方で書ける

## 3. 採用技術の一覧

バージョンは 2026-11-24 に公式の配布元で確認した。

## 4. 主な設計判断

- **アプリのページはアプリごとのフォルダーにまとめる**：`src/pages/apps/<アプリ名>/` に、説明・ポリシー・規約・削除・サポートを置く。アプリを足すときは、このフォルダーとアプリの一覧の1行を足すだけで済む（NF-MT-02）
- **スクリプトを配らない**：Astro の部品は組み立てのときに HTML になる。動きのある部品（Astro の「島」）は使わない（NF-SC-02）
- **出力の形**：最後が `/` の URL にするため、ページごとのフォルダーに `index.html` を書き出す（BR-06）

## 5. 開発環境

- Node.js 26.13.1（Windows は winget の `OpenJS.NodeJS.LTS` で入れる）
- 手元での確かめ：Astro の開発用のサーバー（コマンドは Astro を入れるときに CLAUDE.md の 4.1 に書く）
